# Enterprise MCP 202 internal review Pages

This is a private, internal-review repository. GitHub Pages serves the pressed
lab guides from `internal-review:/docs`.

Only vetted, self-contained HTML and the index page belong in `docs/`. Never
commit source manuscripts, authoring decisions, credentials, tokens, private
URLs, internal discussion, or unpublished working assets.

Do not edit lab HTML in place. Re-press from the internal authoring repository
and replace the complete `docs/` snapshot after review.

Run `bash scripts/publish-checks.sh` before every push. Do not change repository
visibility or Pages access without explicit release approval.
